
# dIAra - Grupo 3

Proyecto integrador de Visualización de Datos
LEAD University - III Cuatrimestre 2026

## Objetivo

Desarrollar una plataforma de monitoreo ciudadano de obras públicas que permita consultar, comprender y visualizar la información generada por dIAra de manera accesible, transparente e interactiva.

## Estructura del repositorio

- data/: Datos originales y procesados.
- scripts/: Extracción, limpieza y automatización.
- frontend/: Plataforma web.
- visualizaciones/: Gráficos y línea de tiempo.
- chatbot/: Asistente ciudadano.
- notificaciones/: Alertas y WhatsApp.
- galeria/: Evidencia fotográfica y comparador.
- pruebas/: Pruebas de usabilidad.
- documentacion/: Informes y evidencias.

## Reglas de trabajo

1. Cada integrante debe trabajar en su rama asignada.
2. No realizar cambios directamente en main.
3. Documentar los cambios realizados.
4. Integrar los cambios mediante Pull Requests.
5. No subir contraseñas, tokens ni claves de API.
6. Identificar claramente los datos simulados.
7. Mantener actualizada la documentación.
8. Cada integrante debe probar su módulo antes de integrarlo.
